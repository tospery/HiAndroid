# 领域文档

工程 skill 探索本仓库时，按以下规则读取术语和架构决策。

## 阅读位置

- 若根目录有 `GLOSSARY.md`，先阅读其中与当前任务相关的术语。
- 若 `docs/adr/` 中有相关架构决策记录，阅读后再修改对应领域。

本仓库采用单上下文布局：`GLOSSARY.md` 位于仓库根目录，ADR 位于 `docs/adr/`。这两个位置目前尚未创建；文件不存在时继续当前任务，无需预先创建。术语或决策实际确定后，可由 `domain-modeling` skill 按需补充。

## 使用约定

在工作项标题、重构方案、假设和测试名称中沿用 Glossary 已定义的术语。遇到缺少的概念时，先核对项目现有用语，再考虑补充 Glossary。

若提议与已有 ADR 冲突，明确指出冲突及重新讨论的理由，不直接覆盖原有决策。
