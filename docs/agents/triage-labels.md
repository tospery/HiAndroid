# 分流标签

工程 skill 使用以下五种标准分流角色。本表定义它们在本仓库 GitHub Issues 中对应的标签。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可以交给智能体处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 决定不处理 |

当 skill 提到某个分流角色时，使用表中对应的本仓库标签。若标签命名以后改变，更新“本仓库标签”一列。
